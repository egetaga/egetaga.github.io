# Ege Onur Taga — simple academic website

This is a small, no-build static website based on the same simple academic layout as yingcong-li.github.io.

## Files

- `index.html` — home, bio, news, and selected publications
- `publications.html` — full publication list
- `style.css` — all styling
- `assets/profile.jpg` — profile photo
- `assets/EgeOnurTaga_CV.pdf` — CV

## Publish with GitHub Pages

Copy these files to the root of the `egetaga.github.io` repository, commit them, and push to the default branch.

No Jekyll, npm, JavaScript framework, or build command is required.

## Publication images

The publication thumbnails are loaded directly from figures in the corresponding arXiv/ar5iv/alphaXiv paper pages. They require an internet connection. Papers without a verified figure URL are displayed without a thumbnail rather than using invented artwork.
